# BraakMan Onepager

Open `index.html` in je browser om de website te bekijken.

Bestanden:
- `index.html` — structuur van de onepager
- `style.css` — donkere BraakMan styling
- `script.js` — animaties en audioplayer
- `assets/braakman.png` — afbeelding van BraakMan
- `assets/BraakMan_theme_song.wav` — theme song
